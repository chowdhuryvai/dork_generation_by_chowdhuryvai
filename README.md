# 🌟 Features
🎯 Core Features
Intelligent Dork Generation - Extracts keywords from any website automatically

4 Different Dork Types - Single, Chained, Advanced & Composite

Real-time Search - Execute dorks using Zyte API

Smart Filtering - Filter, deduplicate & cleanup dorks

Professional UI - Dark theme with intuitive controls

🔧 Technical Features
Zero Dependencies - Uses only Python standard library

Cross-platform - Works on Windows, Linux & macOS

Threaded Operations - Non-blocking UI during searches

Progress Tracking - Real-time progress bar with status updates

Export Functionality - Save dorks and results to files

🛡️ Security Features
API Key Storage - Securely saves Zyte API key

SSL Support - Secure HTTPS connections
